# Wavelet exposition

**From Fourier Analysis to M-Band Wavelets: Multiresolution and Perfect-Reconstruction Filter Banks**  
Jiayu Ellie Su, October 2026

- [PDF](mband_wavelets.pdf)
- [LaTeX source](mband_wavelets.tex)
- [Figure generation and numerical checks](generate_figures.py)

The article covers orthogonal discrete wavelet transforms, multi-band FIR filter banks, vanishing moments, polyphase representations, paraunitary constructions, and the `mbandwt` implementation. The script reproduces the figures and calculates numerical errors using the filters documented in the article.

To build locally (Python with NumPy, SciPy, Matplotlib, and a LaTeX installation):

```bash
python generate_figures.py
pdflatex -interaction=nonstopmode -halt-on-error mband_wavelets.tex
pdflatex -interaction=nonstopmode -halt-on-error mband_wavelets.tex
```

The PDF is generated by the repository's GitHub Actions workflow whenever the source changes.
